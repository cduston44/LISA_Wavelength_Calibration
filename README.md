# LISA_Wavelength_Calibration
Python script to help calibrate the LISA Spectrometer. Intended to be used in conjunction with Demetra.

Essential Instructions (more in the .ipynb file):

1. Download the script (the .ipynb file).
2. Goto https://colab.research.google.com/ and put in your user info
3. Upload the script there.
4. Follow the instructions in the script, which are:

5. Upload the list of LISA lines (exported from Demetra) and the spectrum you want to calibrate to the Colab environment here (folder icon on left bar -> upload, and the spectrum you want is \<object>_Calibration_S.fit)
6. Enter those file names in Cell 2. If you want to play with the parameters, do that here too.
7. Run the script!
8. Check the result, and if it looks good enter the A's into Demetra's calibration routine and continue your work.
